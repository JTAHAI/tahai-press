# Search Desk

Search Desk is static-first. A small deterministic JSON index provides the resilient browser implementation and archive fallback; pinned Pagefind is built after normal static generation as a route-scoped enhancement. Queries never leave the reader’s browser.

The desk supports query state, publication-managed synonyms, format/category controls, accessible result status, reset, and links to archives, topics, contributors, series, hubs, and Knowledge Desk when JavaScript is unavailable.
