# Publisher acceptance test

Before release, confirm a nontechnical publisher can complete Launch Desk, create a draft, preview a story and record, search public content, read a PDF with its HTML alternative, print an edition, download a newsletter export, use the Data and Maps fallbacks, export a review handoff, create a safety copy, and restore it in a fixture. Then run validation, build, accessibility/performance/reader/media audits, browser verification, smoke, release proof, package generation, and the security report.
