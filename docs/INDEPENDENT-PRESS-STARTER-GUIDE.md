# Independent Press starter guide

1. Run Launch Desk and replace the sample identity.
2. Keep drafts in source control, review them, then publish through the normal build.
3. Import existing material with a dry run and retain the reversible transaction.
4. Attach public source records and write a plain-language PDF alternative.
5. Build editions, newsletters, and feeds from canonical content.
6. Make a safety copy before high-risk changes or deployment.
7. Verify the generated site locally before asking an account owner to deploy.

The project does not lock a publisher into a host, CMS account, email service, database, or analytics provider.
