# TAHAI Press technical provenance

TAHAI Press identifies the software that generated a deployment without placing platform branding in a publisher's visible interface.

Every generated HTML page contains:

```html
<meta name="generator" content="TAHAI Press">
```

and this source comment:

```html
<!--
Generated by TAHAI Press
Created by Justin Tahai and TAHAI Web Services
https://tahai.net
-->
```

The build also emits:

- `/humans.txt`
- `/.well-known/tahai-press.json`

These records are technical provenance only. The generator never injects a visible credit, footer attribution, colophon, logo, backlink, hidden keyword block, or TAHAI-related structured data into publisher pages. Public identity, publisher schema, social metadata, colors, contact details, article content, and navigation remain controlled by `content/site.json` and publication content records.

## Public attribution

The Apache 2.0 license applies to the software source and redistributed source distributions. TAHAI Press does not require publishers to display a public banner, powered-by line, footer credit, logo, backlink, hidden link, or other visible project attribution on generated publication pages. When `template_mode` is disabled, the public surface is the publisher's own.
