# Developing coverage

Developing coverage is a static, source-controlled timeline in `content/developing/`. Each record identifies its author, related canonical story and records, what changed, status/finalization state, and timestamped updates with explicit same-origin source links. A pinned update can identify the most important current information.

No live server is needed. Editors update the source record, run validation, review the timeline, and publish through the ordinary repository workflow. Finalization changes the record state without deleting prior updates.
