# Independent Press showcase walkthrough

This fictional TAHAI Press newsroom demonstrates a breaking-news front page, written story, investigation, analysis, public-record PDF, Receipts Mode, evidence record, Data Desk, Maps Desk, developing timeline, records packet edition, newsletter archive, static search, saved stories, offline reading, no-JavaScript fallbacks, local editing, and private recovery tooling.

Start at `/`, then visit `/stories/`, `/records/`, `/data/`, `/maps/`, `/developing/`, `/editions/`, `/newsletters/`, `/search/`, and `/setup/`. Every named organization, person, record, and dataset in the demo is fictional or project-created. Replace it before a real launch.
