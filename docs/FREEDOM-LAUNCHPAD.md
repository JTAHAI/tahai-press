# Freedom Launchpad

Freedom Launchpad is the publisher-facing name for the demo-only Launch Desk at `/setup/`. It is a browser-local, thirteen-step path that produces ordinary files rather than an account or hosted configuration record.

The journey covers identity, visual choices, homepage composition, editor connection, the first story, launch review, mission, trust commitments, safe import planning, the first public record, ownership, recovery, and final readiness. Progress and acknowledgements stay in local storage. The final package is blocked until the ownership, evidence, import, mission, and trust commitments are complete.

Launch packages disable demo mode, retain an auditable `launch_plan`, create a draft rather than a public story, and preserve a backup before local application. No setup request is sent to TAHAI Press or a third party.
