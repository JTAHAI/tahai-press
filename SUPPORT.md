# Support

TAHAI Press is an open-source project maintained through the public repository.

## Before opening an issue

1. Use Node.js 22 or newer.
2. Start from a clean checkout.
3. Run `npm run ci`.
4. Confirm the problem exists in the current `main` branch.
5. Remove private publication material, credentials, and sensitive documents from any reproduction.

## GitHub Issues

Use [GitHub Issues](https://github.com/JTAHAI/tahai-press/issues) for:

- reproducible generator defects;
- broken templates or routes;
- accessibility regressions;
- Pages CMS configuration problems;
- Cloudflare Pages build-contract problems;
- focused feature proposals aligned with the project architecture.

General website projects, custom migrations, and publication operations are outside the guarantee of community support.

## Security reports

Do not open a public issue for a security vulnerability. Follow [SECURITY.md](SECURITY.md).
