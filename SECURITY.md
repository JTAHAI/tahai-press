# Security policy

Please do not publish suspected vulnerabilities in a public issue before maintainers have had a reasonable opportunity to review them.

For a public fork, replace this file with the repository owner's preferred private reporting address or GitHub private vulnerability reporting instructions.

TAHAI Press is static by design and does not include a public application database, server-side form handler, account system, or application secrets. Pages CMS is configured only for public content and media paths; never place credentials or highly sensitive private information in CMS fields or Git history. The release checks generated output for common credential patterns, private editor-note leakage, unsafe source-directory copies, oversized Cloudflare Pages assets, and broken internal routes. Repository permissions, branch protection, account security, Cloudflare response headers, and dependency review remain operator responsibilities.
